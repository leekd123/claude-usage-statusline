# usage-statusline

[English](README.md) | 한국어

프롬프트 아래 상태 줄에 사용량을 보여 주고, 그 사용량을 기록해 브라우저에서 통계 페이지로 볼 수 있게 하는 Claude Code mod입니다. mod 자체는 토큰을 쓰지 않습니다. 엔진이 이미 측정한 값을 읽기만 합니다.

## 상태 줄

```
4% 3:14(5h) · 10% 4d 8:13(7d) · $5.72 / $18.40 · 1.23M tok / 5.20M tok
```

- **rate limit**: 창마다 사용률, 초기화까지 남은 시간(`h:mm` 또는 `Nd h:mm`), 창 길이를 보여 줍니다. 구독 계정만 해당합니다.
- **비용**과 **토큰**: 이 세션 / 오늘 순으로 보여 줍니다.
- 모델 응답이 올 때마다(턴 도중 포함) 갱신됩니다. 1분마다 카운트다운을 다시 그리고 오늘 합계를 다시 읽습니다.
- rate limit은 계정 단위이므로 어느 세션이든 가장 최근에 읽은 값을 공유합니다. 새 세션이나 유휴 세션에도 표시되고, 다른 세션이 작업하면 1분 안에 값이 바뀝니다. 어느 세션이든 응답을 한 번 받기 전에는 표시되지 않습니다.
- 비용과 토큰은 항상 표시되며, 아직 아무것도 사용하지 않은 세션에서는 `$0.00`, `0 tok`으로 나옵니다.

**각 값이 세는 것**

| | |
|---|---|
| 토큰 | 메인 스레드와 subagent의 모든 모델 응답 usage를 합산합니다. 입력·출력·캐시 읽기·캐시 쓰기를 모두 더합니다. 캐시 읽기는 요청마다 대화를 다시 세므로 합계가 컨텍스트 창보다 훨씬 빠르게 늘어납니다. 이 세션에서 mod가 로드된 시점부터 세며, 재개(resume)한 세션은 0부터 다시 셉니다. |
| 비용 | 이 세션에 대한 엔진의 API 가격 기준 추정치입니다. 구독 요금제에서는 실제 청구액이 아닙니다. |
| 오늘 | 로컬 자정 이후 이 기기에서 이 mod로 실행된 세션들의 합계입니다. 다른 기기나 웹의 세션, mod 설치 이전의 세션은 포함되지 않습니다. 한 세션의 전체 비용은 마지막으로 측정된 날에 계산됩니다. |

## 통계 페이지

`/usage-stats`를 실행하면 사용량 기록으로 `stats.html`을 만들어 브라우저로 엽니다. 서버나 네트워크 없이 파일 하나로 되어 있습니다.

**보여 주는 것**

- **rate limit**: 창마다 사용률과 초기화까지 남은 시간입니다. 페이지를 열어 두면 남은 시간이 줄어듭니다.
- **지표별 카드**: 고른 기간의 세션, 턴, 응답, Agent time, 비용, 토큰입니다. 각 카드에 직전 같은 기간 대비 증감률이 나옵니다.
- **차트**: 위 지표 중 하나의 일별 막대 차트입니다. 날짜에 마우스를 올리면 수치가 나옵니다.
- **Breakdown**: 날짜별, 모델별, 날짜·모델별로 묶거나, 묶지 않고 고른 기간 전체를 한 줄로 보는 표입니다. 턴은 특정 모델에 속하지 않으므로 Turns와 Agent time 열은 모델로 묶지 않은 표에만 나옵니다.
- **Sessions**: 고른 기간에 쓴 세션을 최근에 쓴 것부터 한 줄씩 보여 줍니다. 제목, 프로젝트, 처음과 마지막 사용 시각(지역 시간), 턴, 응답, Agent time, 토큰, 비용이 나옵니다.

**바꿀 수 있는 것**

- **기간**: 위쪽의 Today, 7d, 30d, 90d, All 버튼입니다.
- **프로젝트**: 왼쪽 사이드바에서 모든 내용을 프로젝트별로 걸러 봅니다. 프로젝트를 기록하기 전의 줄은 `(no project)`에, 폴더를 고르지 않은 대화를 위해 데스크톱 앱이 만드는 폴더(`scratch-<날짜>-<id>`)는 모두 `(scratch)` 하나에 들어갑니다.
- **차트 지표**와 **Breakdown 묶음**: 차트 위 버튼과 Breakdown 위 Day, Model 체크박스입니다.
- **테마**: 사이드바 아래쪽의 Light, Dark, System 버튼입니다.
- **자동 새로 고침**: 사이드바 아래쪽 Auto refresh 버튼 옆에 다음 새로 고침까지 남은 초가 나오고, 이 버튼으로 끄고 켭니다.

고른 값은 모두 브라우저가 기억합니다. 사이드바 아래쪽에는 이 저장소의 GitHub 링크도 있습니다.

**갱신 시점**

- mod는 세션이 시작될 때(`/reload-plugins` 포함), 턴이 끝날 때마다, 그리고 새 응답이 기록된 경우 1분마다 페이지를 다시 만듭니다. 긴 턴 도중에도 값이 반영됩니다.
- 페이지는 1분마다 스스로 새로 고치므로 열어 두거나 북마크해 두기만 하면 됩니다.
- mod는 기록을 날짜·프로젝트·세션·모델별로 합산해 페이지에 넣고, 페이지의 스크립트가 그것으로 화면을 그립니다. 선택을 바꿀 때 페이지를 다시 만들 필요가 없습니다.
- 사이드바 아래쪽에 마지막으로 만드는 데 걸린 시간과 읽은 줄 수가 나옵니다. 만들 때마다 모든 기록을 읽으므로, 이 시간이 1초 정도를 넘기 시작하면 날짜별 합계를 저장하는 방식으로 바꿀 때입니다.

## 사용량 기록

usage를 보고하는 모델 응답마다, 로컬 날짜와 세션마다 하나씩 있는 파일에 JSON 한 줄을 덧붙입니다:

```
~/.claude/usage-statusline/<YYYY-MM-DD>.<세션 id>.jsonl
```

(`CLAUDE_CONFIG_DIR`가 설정되어 있으면 그 아래에 둡니다.) 응답 한 줄의 예:

```
{"t":"2026-11-17T01:03:12.000Z","session":"…","project":"…","agent":"…","model":"…","input":1000,"output":2000,"cacheRead":40000,"cacheWrite":7000,"cost":0.12}
```

| 필드 | 의미 |
|---|---|
| `project` | 세션 루트 폴더의 이름입니다. |
| `agent` | subagent의 응답에만 있습니다. |
| `cost` | 이전 줄 이후 늘어난 이 세션의 추정 비용입니다. 한 응답의 비용이 다음 줄에 잡힐 수 있지만 하루 합계는 정확합니다. |

메인 턴이 끝날 때마다 토큰 없이 `"turn":true`인 줄을 하나 남겨 페이지에서 턴 수를 셉니다. 턴 하나(메시지 하나와 그에 대한 답)에는 모델 요청마다 하나씩, 응답이 여러 개 들어 있습니다. 이 줄에는 다음도 들어갑니다:

- `ms`: 그 턴에 걸린 시간입니다.
- `title`: Claude Code에 표시되는 세션 제목으로, 대화 기록 파일의 마지막 `custom-title` 줄입니다. ponytail처럼 `grep`으로 읽고, Git의 `grep`이 PATH에 없는 경우가 많은 Windows에서는 `findstr`로 읽습니다.

제목이나 프로젝트가 기록되지 않은 세션(그 기록을 시작하기 전에 시작한 세션)은 모든 프로젝트 폴더에서 그 세션의 대화 기록을 찾아, 마지막 `custom-title` 줄과 줄마다 적힌 `cwd` 폴더 이름을 한 번 읽습니다. 결과는 mod 저장소에 남겨 같은 대화 기록을 두 번 읽지 않습니다. 대화 기록이 없는 세션은 세션 id 앞부분과 `(no project)`로 나옵니다.

파일이 3 MiB를 넘으면 그대로 두고 `<YYYY-MM-DD>.<세션 id>.2.jsonl`, `.3` 순으로 이어서 씁니다. mod는 이 파일을 쓰기만 하고 지우지 않습니다.

## 설치

Claude Code 터미널 세션의 프롬프트에서:

```
/plugin install usage-statusline --marketplace leekd123/claude-usage-statusline
```

marketplace 추가를 물으면 `y`로 답한 뒤 scope를 고릅니다(user가 첫 번째). 셸에서 설치하려면:

```bash
claude plugin install usage-statusline --marketplace leekd123/claude-usage-statusline
```

`/plugin`이 동작하지 않는 데스크톱 앱에서는: 프롬프트 입력란 옆 + 를 누르고 Plugins → Add marketplace에 `leekd123/claude-usage-statusline`을 입력한 뒤 Add plugin을 누릅니다.

이미 실행 중인 세션은 `/reload-plugins`로 적용되고, 새 세션은 자동으로 로드합니다.

## 개발

로컬 클론에서 설치하면 수정 사항이 재설치 없이 `/reload-plugins`만으로 세션에 반영됩니다:

```bash
claude plugin marketplace add <클론 경로>
```

```bash
claude plugin install usage-statusline@usage-statusline --scope user
```

```bash
claude plugin validate .
```

```bash
claude plugin test .
```
