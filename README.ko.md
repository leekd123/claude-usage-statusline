# usage-statusline

[English](README.md) | 한국어

프롬프트 아래 상태 줄에 사용량을 표시하는 Claude Code mod입니다. 각 rate-limit 창(사용률, 초기화까지 남은 시간을 `h:mm` 또는 `Nd h:mm`로, 창 길이)에 이어 비용과 토큰을 각각 이 세션 / 오늘 순으로 보여 줍니다:

```
4% 3:14(5h) · 10% 4d 8:13(7d) · $5.72 / $18.40 · 1.23M tok / 5.20M tok
```

모델 응답이 올 때마다(턴 도중 포함) 갱신되며, 1분마다 카운트다운을 다시 그리고 오늘 합계를 다시 읽습니다. rate limit은 계정 단위이므로 어느 세션이든 가장 최근에 읽은 값을 공유합니다. 새 세션이나 유휴 세션에도 표시되고, 다른 세션이 작업하면 1분 안에 값이 바뀝니다(구독 계정만 해당하며, 어느 세션이든 응답을 한 번 받기 전에는 표시되지 않습니다). 비용과 토큰은 항상 표시되며, 아직 아무것도 사용하지 않은 세션에서는 `$0.00`, `0 tok`으로 나옵니다. mod 자체는 토큰을 쓰지 않습니다. 엔진이 이미 측정한 값을 읽어 화면에 그리기만 합니다.

**토큰**은 각 모델 응답의 usage(메인 스레드와 subagent 모두)를 합산하며, 입력·출력·캐시 읽기·캐시 쓰기 네 가지를 모두 더합니다. 캐시 읽기는 요청마다 대화를 다시 세기 때문에 합계가 컨텍스트 창보다 훨씬 빠르게 늘어납니다. 이 세션에서 mod가 로드된 시점부터 세며, 재개(resume)한 세션은 0부터 다시 셉니다. **비용**은 이 세션에 대한 엔진의 API 가격 기준 추정치이며, 구독 요금제에서는 실제 청구액이 아닙니다.

**오늘 합계**(비용과 토큰)는 로컬 자정 이후 이 기기에서 이 mod로 실행된 세션들을 합산하며, 각 세션은 mod 저장소에 자체 키로 보관됩니다. 다른 기기나 웹의 세션, mod 설치 이전의 세션은 포함되지 않습니다. 한 세션의 전체 비용은 마지막으로 측정된 날에 계산됩니다.

**사용량 기록.** usage를 보고하는 모델 응답마다 `~/.claude/usage-statusline/<YYYY-MM-DD>.<세션 id>.jsonl`(`CLAUDE_CONFIG_DIR`가 설정되어 있으면 그 아래)에 JSON 한 줄을 덧붙입니다. 로컬 날짜와 세션마다 파일이 하나씩이며, 직접 통계를 낼 때 씁니다:

```
{"t":"2026-11-17T01:03:12.000Z","session":"…","project":"…","agent":"…","model":"…","input":1000,"output":2000,"cacheRead":40000,"cacheWrite":7000,"cost":0.12}
```

`project`는 세션 루트 폴더의 이름입니다. `agent`는 subagent의 응답에만 있습니다. 메인 턴이 끝날 때마다 토큰 없이 `"turn":true`인 줄을 하나 남겨 페이지에서 턴 수를 셉니다. 이 줄의 `ms`에는 그 턴에 걸린 시간이, `title`에는 Claude Code에 표시되는 세션 제목이 들어갑니다. 제목은 대화 기록 파일의 마지막 `custom-title` 줄에서 읽습니다. ponytail처럼 `grep`을 쓰고, Git의 `grep`이 PATH에 없는 경우가 많은 Windows에서는 `findstr`을 씁니다. 턴 하나(메시지 하나와 그에 대한 답)에는 모델 요청마다 하나씩, 응답이 여러 개 들어 있습니다. `cost`는 이전 줄 이후 늘어난 이 세션의 추정 비용이라, 한 응답의 비용이 다음 줄에 잡힐 수 있습니다. 하루 합계는 정확합니다. 파일이 3 MiB를 넘으면 그대로 두고 `<YYYY-MM-DD>.<세션 id>.2.jsonl`, `.3` 순으로 이어서 씁니다. mod는 이 파일을 쓰기만 하고 지우지 않습니다.

**통계 페이지.** `/usage-stats`를 실행하면 모든 날짜의 기록 파일로 기록 폴더에 `stats.html`을 만들어 브라우저로 엽니다. 각 rate-limit 창(어느 세션이든 가장 최근에 읽은 값의 사용률과 초기화까지 남은 시간, 페이지를 열어 두면 남은 시간이 줄어듦), 오늘, 최근 7일, 최근 30일, 전체 합계와 최근 30일 일별 토큰 막대 차트(날짜에 마우스를 올리면 수치 표시), 집계 표를 보여 줍니다. 표 위의 Day, Model 체크박스로 날짜별, 모델별, 날짜·모델별로 묶거나, 둘 다 해제해 전체 기간 한 줄로 볼 수 있으며, 고른 값은 브라우저가 기억합니다. 턴은 특정 모델에 속하지 않으므로 Turns와 Agent time 열은 모델로 묶지 않은 표에만 나옵니다. 그 아래 세션 표에는 최근에 쓴 세션부터 세션마다 한 줄씩 제목(아직 없으면 세션 id 앞부분), 프로젝트, 처음과 마지막 사용 시각(지역 시간), 턴, 응답, Agent time, 토큰, 비용이 나옵니다. 왼쪽 사이드바에서 프로젝트별로 걸러 볼 수 있으며(프로젝트를 기록하기 전의 줄은 `(no project)`에 들어감), 고른 값은 브라우저가 기억합니다. 사이드바 아래쪽 Light, Dark, System 버튼으로 테마를 고르며, 고른 값은 브라우저가 기억합니다. 그곳의 링크로 이 저장소의 GitHub 페이지를 열 수 있습니다. 서버나 네트워크 없이 파일 하나로 되어 있습니다. mod는 세션이 시작될 때(`/reload-plugins` 포함), 턴이 끝날 때마다, 그리고 새 응답이 기록된 경우 1분마다 이 파일을 다시 만들므로 긴 턴 도중에도 값이 반영됩니다. 페이지는 1분마다 스스로 새로 고치므로 열어 두거나 북마크해 두기만 하면 됩니다. 사이드바 아래쪽 Auto refresh 버튼 옆에 다음 새로 고침까지 남은 초가 나오며, 이 버튼으로 자동 새로 고침을 끄고 켤 수 있고 고른 값은 브라우저가 기억합니다. 사이드바 아래쪽에 마지막으로 만드는 데 걸린 시간과 읽은 줄 수가 나옵니다. 만들 때마다 모든 기록을 읽기 때문에, 이 시간이 1초 정도를 넘기 시작하면 날짜별 합계를 저장하는 방식으로 바꿀 때입니다.

## 설치

Claude Code 터미널 세션의 프롬프트에서:

```
/plugin install usage-statusline --marketplace leekd123/claude-usage-statusline
```

marketplace 추가를 물으면 `y`로 답한 뒤 scope를 고릅니다(user가 첫 번째). 셸에서 설치하려면:

```bash
claude plugin install usage-statusline --marketplace leekd123/claude-usage-statusline
```

`/plugin`이 동작하지 않는 데스크톱 앱에서는: 프롬프트 입력란 옆 + 를 누르고 Plugins → Add marketplace에 `leekd123/claude-usage-statusline`을 입력한 뒤 Add plugin을 누릅니다.

이미 실행 중인 세션은 `/reload-plugins`로 적용되고, 새 세션은 자동으로 로드합니다.

## 개발

로컬 클론에서 설치하면 수정 사항이 재설치 없이 `/reload-plugins`만으로 세션에 반영됩니다:

```bash
claude plugin marketplace add <클론 경로>
```

```bash
claude plugin install usage-statusline@usage-statusline --scope user
```

```bash
claude plugin validate .
```
